# Пользовательский архив AstroDay

## Формат

Полный экспорт использует JSON-конверт:

- `format`: `astroday-user-archive`;
- `schemaVersion`: `1`;
- `exportedAt`: ISO timestamp создания;
- `data`: полный набор пользовательских данных.

Архив содержит:

1. Основной профиль и настройки точности времени.
2. Ежедневную обратную связь и заметки.
3. Калибровку севера.
4. План помещения: изображение, комнаты, поворот сетки и маркеры.
5. Прогресс по домашним задачам.
6. Чек-лист Васту.
7. Паспорт/финансовую оценку недвижимости.
8. Отдельный профиль партнёра.

Пересчитываемые прогнозы IndexedDB не экспортируются: они являются кэшем и могут быть построены заново на основе профиля.

## Восстановление

`restoreUserArchive(json)` выполняет два этапа:

1. Разбирает JSON и проверяет версию формата, профиль, координаты, IANA timezone и структуру каждой сущности.
2. Только после успешной проверки записывает данные в локальное хранилище.

Перед записью сохраняются прежние значения всех затрагиваемых ключей. Если запись прерывается (например, из-за quota/security error), выполняется откат к прежним значениям. Если сам откат не удаётся, интерфейс получает отдельное предупреждение и не сообщает об успешном восстановлении.

Поддерживаются оба старых формата: прежний полный JSON без envelope/version (профиль, feedback, дом и партнёр) и отдельный JSON профиля. Старый полный пакет восстанавливается целиком после той же проверки; файл только с профилем обновляет только профиль и не удаляет остальные разделы.

## Ошибки хранения

Функции сохранения не скрывают ошибки localStorage. Вызывающий компонент получает исключение и должен оставить редактируемое состояние на экране, показать сообщение и не отображать статус «сохранено».

Для quota errors показывается рекомендация освободить место или сначала скачать архив. При security errors предлагается проверить настройки приватности и разрешение браузера на локальное хранение. Данные формы остаются в состоянии React до повторной попытки или ухода со страницы.

## Ограничения и безопасность

- Хранение остаётся локальным: серверной синхронизации или облачной резервной копии нет.
- XOR + Base64 — обратимая обфускация, а не криптографическое шифрование.
- Архив содержит персональные данные рождения и местоположения. Храните скачанный JSON в безопасном месте и не передавайте его посторонним.
- Лимит размера импортируемого JSON — 50 МБ; фактическая ёмкость localStorage обычно существенно меньше и зависит от браузера.
- Архив не включает кэш прогнозов IndexedDB.
- При неудаче записи интерфейс не должен обещать, что данные сохранены; пользователь может скачать архив и повторить действие после освобождения места.

## Regression coverage

`storage.test.ts` проверяет экспорт/восстановление всех разделов, legacy-импорт профиля, отказ до записи для некорректного архива, quota failure и rollback ранее сохранённых значений. Полный `npm run verify` требуется выполнить на итоговом commit.
